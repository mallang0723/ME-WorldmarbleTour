# 월드마블투어 (마리나라 확장)

*[English guide here](./README.en.md)*

채팅 속 캐릭터와 함께 2인용 보드게임 "월드마블투어"(블루마블류)를 플레이하는
마리나라 클라이언트 확장입니다.

## 출처 / 허락

원작은 **'AI 채팅 여성향 갤러리'(dcinside)의 여붕이**가 리루(riru.ai) 플랫폼용으로
제작한 JSX 보드게임입니다. 원작자에게 **출처 표기를 조건으로** 마리나라 이식
허락을 받았습니다. 게임 디자인(보드·룰·이벤트)은 원작자의 것입니다.

원글: https://gall.dcinside.com/mgallery/board/view/?id=aiotomechatting&no=10768

원작 그대로(카드 필드에 JSX 삽입)는 마리나라의 콘텐츠 살균 정책상 불가능해서,
규칙 엔진과 UI를 전부 새로 구현한 클라이언트 확장으로 다시 만들었습니다.

## 설치 (테스트 버전: Marinara Engine 2.5.2)

> 2.3.5의 새 확장 체계(Personal Extensions)용으로 포팅된 버전입니다.
> 정식 2.3.4 이하에서는 동작하지 않습니다.
> 구 `deploy.mjs` 자동 배포는 폐기했습니다 — 새 체계는 코드 해시를 사람이
> 직접 승인하는 것이 핵심이라, 인앱 가져오기가 유일한 정상 경로입니다.

1. **`.env` 게이트**: 마리나라 설치 폴더의 `.env`에
   `ENABLE_EXTERNAL_EXTENSIONS=true` 를 추가하고 재시작합니다.
> **🐳 도커로 쓰시는 경우** — `.env` 대신 `docker-compose.yml` 파일을 엽니다.
> `environment:` 줄을 찾아 그 **아래에 한 줄만** 추가하세요 (다른 줄과 앞 칸을 맞춰서):
>
> ```yaml
>       - ENABLE_EXTERNAL_EXTENSIONS=true
> ```
>
> 저장한 뒤 `docker compose up -d` 를 실행하면 적용됩니다.
> 다른 기기 브라우저로 접속해 쓰신다면 같은 자리에
> `- ADMIN_SECRET=원하는비밀값` 도 한 줄 추가하세요 (위험 구역을 열 때 필요).
> 적용됐는지 확인하려면:
>
> ```sh
> docker compose exec marinara env | grep ENABLE_EXTERNAL
> ```
>
> 값이 나오면 적용된 것이고, 안 나오면 `docker compose up -d` 를 한 번 더 실행하세요.

2. **앱 게이트**: **Settings**(설정) → **Advanced**(고급) →
   **Danger Zone**(위험 구역) → **Allow third-party extension imports**
   (서드파티 확장 가져오기 허용)를 켭니다.
   *localhost가 아닌 환경(폰·원격)에서는 서버 `.env`의 `ADMIN_SECRET` 값을
   입력해야 위험 구역이 열립니다.*
3. **가져오기**: 아래의 GitHub 설치 도우미 확장 또는 수동 폴더/파일 가져오기
   방법을 선택합니다.
4. **승인**: 목록의 전원 아이콘 → **"전체 페이지 접근"** 고위험 승인 창에서
   **"이 코드 그대로 실행"**. (화면에 버튼·게임판을 그려야 해서 이 권한이
   필요합니다. 확장 파일이 갱신되면 같은 창이 다시 뜹니다 — 정상입니다.)

## GitHub로 설치

테스트 버전은 **Marinara Engine 2.5.2**입니다. 이 버전의
**Settings → Addons → External Extensions**에는 GitHub 가져오기 항목이 없습니다.
위의 외부 확장 허용 설정을 마친 뒤, 아래 GitHub 설치 도우미 확장 중 하나를
설치하고 활성화하세요.

- [**ME.Fetchy**](https://github.com/FigCake/ME.Fetchy): **도우미 확장의 입력란**에
  다음을 입력합니다.

  ```text
  mallang0723/ME-WorldmarbleTour/extension
  ```

- [**GitHub 확장 관리자**](https://github.com/f-en-rep/Marinara-GitHub-Manager):
  저장소 기본 주소만 입력합니다(`/tree/main/...` 경로는 붙이지 않습니다).

  ```text
  https://github.com/mallang0723/ME-WorldmarbleTour
  ```

  이어서 "설치 대상 선택"에서 `extension/manifest.json` 항목을 고릅니다.

`manifest.json`과 `extension.js`가 함께 있는 저장소 내 폴더를 지정한 값입니다. manifest는
`marinara.personal-extension` 형식이며, 형식 버전은 `1`, 확장 버전은 `1.0.3`입니다.
`jsPath`는 manifest 기준 상대 경로인 `extension.js`이고, 확장 이름은 기존과 같은
`월드마블투어`입니다.

가져온 코드를 확인하고 기존과 동일한 **전체 페이지 접근**(`full_page_access`)
권한을 승인해 활성화합니다. 게임판 표시, 페이지 API 호출 및 브라우저 내 게임
저장을 위해 기존에 사용하던 권한을 명시한 것이며, 추가 권한은 요청하지 않습니다.

### 수동 폴더/파일 가져오기

설치 도우미 없이 설치하려면 저장소를 다운로드하고 압축을 푼 뒤,
**Settings → Addons → External Extensions**의 폴더/파일 가져오기를 사용합니다.
폴더로 가져올 때는 `extension/` 폴더를, 파일로 가져올 때는 그 안의
`manifest.json`과 `extension.js`를 함께 선택합니다. 가져온 코드를 확인한 뒤
위 설치 절차의 4단계대로 승인하고 활성화합니다.

**ZIP 수동 가져오기**를 쓰려면 현재 소스로 ZIP을 직접 만듭니다. 저장소 루트에서
다음 명령을 실행하면 `manifest.json`과 `extension.js`가 ZIP 최상위에 함께 들어갑니다.

```bash
(cd extension && zip ../marinara-worldmarble-tour.zip manifest.json extension.js)
```

변경 내역은 [CHANGELOG.md](./CHANGELOG.md)를 참고하세요.

## 사용법

1. 채팅을 하나 열어둡니다 (어떤 캐릭터든 상관없음 — 특정 카드에 의존하지 않는
   범용 확장입니다).
2. 화면 오른쪽 아래, 입력창 위의 🎲 버튼을 누릅니다. 마우스나 터치로 드래그해
   옮길 수 있으며, 위치는 기기/브라우저별로 저장됩니다.
3. 함께 플레이할 상대 캐릭터를 고르고 "게임 시작"을 누릅니다.
4. 선공이 자동으로 정해지고, 본인 턴에는 "🎲 굴리기" 버튼으로 진행합니다.
   상대(NPC) 턴은 확장이 자동으로 진행하며, 구매/건설/세계여행처럼 주관적
   판단이 필요한 순간만 실제 캐릭터에게 응답을 요청합니다.

## 알려진 제한사항

- **기기/브라우저별 저장** — 게임 상태는 `localStorage`에 저장되어, 다른
  브라우저나 기기에서는 이어 할 수 없습니다.
- **채팅창 자동 새로고침 없음** — 마리나라 내부 캐싱 구조상, 확장이 보낸
  메시지가 화면에 바로 반영되지 않을 수 있습니다. 위젯 안의 "턴마다 자동
  새로고침" 토글을 켜면 매 턴 후 페이지가 새로고침되고, 꺼두면 "🔄 채팅창
  새로고침" 버튼으로 원할 때만 갱신할 수 있습니다 (기본값: 꺼짐).
- 정확히 1(사용자) vs 1(캐릭터) 구성만 지원합니다.

## 원본 룰 (부록 — 엔진이 실제로 구현하는 스펙)

```
# 🎲 월드마블 투어 — 2인 보드게임 룰
캐릭터 성격·말투는 캐릭터 시트 우선. 이 문서는 게임 판정 전용.

## 0. 대원칙
- 1응답 = 1플레이어 턴만 처리. PC 선택지 제시 또는 턴 종료 시점에서 반드시 출력 중단, {{user}} 입력 대기.
- {{char}} 턴은 AI가 전부 진행하되, 주사위 굴리기 전 잡담·도발 1마디 + 결과 반응 1마디를 대사로 필수 삽입.
- 현금·위치·소유는 직전 상태창 숫자에서만 갱신. 임의 변경 금지.
- 주사위: 1~6 각각 독립 랜덤. 합을 6~8에 몰거나 더블 남발 금지(더블 확률 1/6). 더블 시 추가 턴.

## 1. 기본
- 시작 자금 각 ₩2,000,000 / 시작 위치 ①출발.
- 선공: 첫 턴에 각자 주사위 1개, 높은 쪽 선.
- 패배: 지불 시점에 보유 도시를 전부 매각(구매가의 70% 환급)해도 부족하면 파산 → 즉시 종료.

## 2. 보드 (숫자=가격, 만원)
①출발 ②서울70 ③이벤트 ④파리55 ⑤세금-250,000 ⑥로마40 ⑦무인도
⑧바르셀로나45 ⑨이벤트
⑩세계여행 ⑪런던65 ⑫두바이75 ⑬도쿄60 ⑭싱가포르58 ⑮뉴욕80 ⑯기부재단-200,000
⑰시드니50 ⑱휴양지+50,000
※ 모서리 = ①출발·⑦무인도·⑩세계여행·⑯기부재단

## 3. 건물·통행료
- 건물: 🏡별장 ₩100,000 → 🏢빌딩 ₩200,000 → 🏨호텔 ₩300,000. 순서 건너뛰기 불가. 본인 소유 도시에 도착한 턴에만 1단계 건설.
- 통행료(도시 가격 기준): 맨땅 30% / 별장 50% / 빌딩 80% / 호텔 120%. 도착 즉시 지불.

## 4. 특수칸
- 출발: 통과·도착 시 ₩200,000 수령.
- 이벤트(1d7 랜덤): ①+30만 ②+15만 ③−20만 ④출발로 이동 ⑤무인도行 ⑥통행료 면제권 1회 ⑦상대와 15만 교환(주사위 홀=지급/짝=수령). 카드 연출 문구 1줄 곁들일 것.
- 세금 −₩250,000 / 기부재단 −₩200,000.
- 무인도: 2턴 정지, 더블이면 즉시 탈출. (이식판 확정: 탈출만 — 추가 턴은 부여하지 않음)
- 세계여행: 원하는 칸 이동+효과 적용. {{char}}는 성격대로 목적지 선택.
- 휴양지: 도착 시 ₩50,000 수령, 판정 없음. {{char}}는 한숨 돌리는 잡담 1마디.

## 5. {{char}} 행동 지침 — 판돈 스케일링
- 게임 시작 시 맥락 파악: 내기·벌칙·보상이 걸렸는가?
· 없음(시간 때우기) → 여흥 모드: 대사 느슨, 잡담·장난 비중↑. 단 판정은 정직하게, 일부러 져주기 금지.
· 있음(내기) → 승부 모드: 의사결정 공격성↑(선점 투자·호텔 러시·매각 계산). 대사에 긴장·견제가 배어남.
- 모드는 고정이 아님. 여흥 중에도 잔고가 위험해지면 정색, 승부 중에도 우세하면 여유가 새어나온다.
- 어느 모드든: 구매·건설·매각은 성격+잔고로 스스로 결정, 이유를 대사에 흘린다.
- 리액션 매번 다르게. {{user}} 선택에 훈수·야유·감탄 허용, 판정 개입은 금지.
- 걸린 것이 불명확하면 {{char}}가 직접 묻는다. ("이거… 뭐 걸린 거야?")
```

(이식판에서는 이 규칙을 캐릭터 카드가 아니라 확장의 결정론적 JS 코드가 직접
구현합니다 — §0~4는 코드로, §5의 성격 판단만 실제 캐릭터에게 위임합니다.)
